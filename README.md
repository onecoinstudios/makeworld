# MakeWorld

**Working title:** MakeWorld
**Genre:** Hybrid casual — creative make-and-play sandbox × collection / evolution meta
**Status:** Concept / pre-production design

## Overview

MakeWorld is a hybrid casual game where players create (outfits, scenes, creations)
and the game turns those creations into a living collection that evolves.

- **Core loop:** Make → Play / Use → Collect & Evolve → Share
- **Sessions:** 1–3 minutes
- **Platform target:** HTML5 / WebGL browser (Playgama-class portal), cross-platform mobile + desktop
